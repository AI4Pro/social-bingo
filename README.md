# Social Bingo — Break the Ice, Fast

Social Bingo turns mingling into a game: give each player a unique 5x5 board of prompts, find people who match the prompts, and shout BINGO when you get five in a row. Perfect for meetups, classrooms, conferences, and remote team warmups.

Why it’s great

- Fast to set up — runs locally with Node + Vite.
- Tiny and focused UI — play, persist, and share boards without friction.
- Designed for events — friendly prompts, free center, and accessible controls.

Highlights

- 5x5 bingo board with a free center
- LocalStorage persistence so games survive refreshes
- Small, composable React components for easy theming and reuse

Quick start

```bash
# Install dependencies
npm ci

# Start dev server (Vite)
npm run dev
```

Build & deploy

```bash
npm run build
# Project is configured to deploy to GitHub Pages on pushes to `main`.
```
