# Welcome to Social Bingo

Thanks for checking out Social Bingo  a tiny React + Tailwind app for getting people talking.

Quick Start:

- Install dependencies: `npm ci`
- Start dev server: `npm run dev` (opens at http://localhost:5173)
- Run tests: `npm test`
- Lint: `npm run lint`

Quick Tour:

- **Start Screen:** Click "New Game" and pick a theme.
- **Game Screen:** Tap squares that match someone nearby. First to get five in a row wins!
- **Free Space:** The center square is free and already marked.
- **Bingo Modal:** When you win, a dialog congratulates you and offers to reset.

Contribute:

- Update the question set at `src/data/questions.ts` to add new prompts.
- Add tests under `src/utils` to validate game logic.
- Run `npm run build` to produce a static site for GH Pages.

That's all  have fun!
